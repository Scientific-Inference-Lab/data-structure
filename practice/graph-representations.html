개념 확인: Graph Representations

같은 그래프를 인접행렬과 인접리스트로 적고 연산·공간 비용을 비교한다.

문제 1

인접행렬로 적기

문제 1~3은 정점 0, 1, 2, 3, 4와 유향 간선 0→1, 0→2, 1→3, 2→3, 3→1, 4→0으로 이루어진 그래프 G를 쓴다.

  1. G의 인접행렬을 0과 1로 적는다(i행 j열이 i→j).
  2. 행렬의 칸 수와 1인 칸 수를 적는다.
  3. hasEdge(2, 3)과 hasEdge(3, 2)를 행렬에서 어떻게 확인하는지와 결과, 비용을 적는다.
  4. 정점 1의 진출 이웃을 행렬에서 모두 찾는 방법과 비용을 적고, 이웃이 하나뿐인데도 비용이 줄지 않는 이유를 적는다.
해설 펼치기
행01234
001100
100010
200010
301000
410000
  1. 위 표와 같다.
  2. 5 × 5 = 25칸 중 1은 6칸이다.
  3. 2행 3열 한 칸을 읽어 참, 3행 2열을 읽어 거짓이다. 각각 O(1)이다.
  4. 1행의 5칸을 모두 훑어 3을 찾는다. O(n)이다. 이웃이 어느 칸에 있는지 모르므로 한 행 전체를 확인해야 한다.
문제 2

인접리스트로 적기

문제 1의 유향 그래프 G를 쓴다.

  1. G의 인접리스트를 정점별 배열 목록으로 적는다.
  2. 인접리스트가 저장하는 항목 수를 n + m으로 구하고 인접행렬의 칸 수와 비교한다.
  3. 배열 목록에서 hasEdge(0, 2)의 비용과, 중복을 막으며 간선 0→2를 추가하는 비용을 적는다. 목록을 set으로 바꾸면 어떻게 달라지는지도 적는다.
  4. 정점 3으로 들어오는 간선을 모두 찾는 과정과 비용을 적는다.
해설 펼치기
  1. 0: [1, 2], 1: [3], 2: [3], 3: [1], 4: [0]이다.
  2. 5 + 6 = 11개로, 인접행렬의 25칸보다 적다.
  3. 배열은 0의 목록을 훑으므로 둘 다 0의 차수만큼 든다. set이면 둘 다 기대 O(1)이다.
  4. 모든 정점의 목록을 훑어 3이 들어 있는 1과 2를 찾는다. O(n + m)이다. 자주 필요하면 들어오는 간선 목록을 따로 둔다.
문제 3

차수 세기

문제 1의 유향 그래프 G를 쓴다.

  1. G의 각 정점의 진출 차수와 진입 차수를 적는다.
  2. 진출 차수의 합과 진입 차수의 합을 구하고 m과 비교해 그 이유를 적는다.
  3. 자기 루프가 없는 유향 그래프에서 정점 n = 5일 때 간선은 최대 몇 개인지 구한다.
  4. 인접행렬과 인접리스트에서 정점 3의 진입 차수를 세는 방법과 비용을 각각 적는다.
해설 펼치기
  1. 진출: 0은 2, 1·2·3·4는 1. 진입: 0은 1, 1은 2, 2는 1, 3은 2, 4는 0.
  2. 둘 다 6으로 m과 같다. 간선 하나는 한 정점의 진출 차수와 다른 한 정점의 진입 차수에 정확히 한 번씩 세어진다.
  3. n(n − 1) = 5 × 4 = 20개다.
  4. 인접행렬은 3열의 n칸을 세므로 O(n)이다. 인접리스트는 모든 목록을 봐야 하므로 O(n + m)이다.
문제 4

무향과 가중치

정점 A, B, C, D와 무향 간선 {A, B}, {A, C}, {B, C}, {C, D}로 이루어진 그래프 H가 있다.

  1. H의 인접행렬에서 1인 칸 수를 적고 행렬의 모양을 적는다.
  2. 대각선 위쪽 절반만 저장하면 칸 수가 얼마인지(대각선 포함) 구하고, 그래도 공간 복잡도가 O(n²)인 이유를 적는다.
  3. 간선 {C, D}에 거리 7이 붙어 있다면 행렬 칸에 무엇을 담는지 적고, 참·거짓만 담을 때 답할 수 없는 질문을 적는다.
  4. H의 인접리스트에서 목록 항목 수의 합을 구한다.
해설 펼치기
  1. 간선마다 (i, j)와 (j, i) 두 칸이므로 8칸이다. 대각선을 기준으로 대칭이다.
  2. n(n + 1)/2 = 4 × 5/2 = 10칸이다. 여전히 n²에 비례해 늘어나므로 O(n²)이다.
  3. C행 D열과 D행 C열에 7을 담는다. 참·거짓만 담으면 간선의 가중치(거리)를 물을 수 없다.
  4. 각 무향 간선이 두 목록에 한 번씩 나타나므로 2 × 4 = 8이다.
문제 5

표현 고르기

  1. 정점 10,000개, 간선 50,000개인 도로망에서 인접행렬의 칸 수와 인접리스트의 n + m을 구하고, 이 그래프가 희소한지 판단한다.
  2. 각 정점의 이웃을 차례로 모두 방문하는 작업이 주로 일어난다면 어느 표현이 유리한지와 이유를 적는다.
  3. 정점 200개에 거의 모든 쌍의 간선 존재를 반복해서 물어야 하고 정점 수가 고정이라면 무엇을 고려할지 적는다.
  4. 정점 이름이 역 이름 문자열이고 역이 자주 추가될 때, 두 단계 사전 G에서 G[u][v]로 간선을 읽는 인접리스트가 알맞은 이유를 적는다.
해설 펼치기
  1. 인접행렬 10,000² = 100,000,000칸, 인접리스트 10,000 + 50,000 = 60,000이다. 가능한 간선에 비해 실제 간선이 아주 적어 희소하다.
  2. 인접리스트다. 이웃 열거가 정점마다 차수만큼이라 전체가 O(n + m)이고, 인접행렬은 정점마다 O(n)이 든다.
  3. 간선 확인이 O(1)인 인접행렬이 후보다. n² = 40,000칸이 감당할 만한지와 이웃 열거 빈도를 함께 본다. 이웃을 set에 담은 인접리스트도 기대 O(1)이다.
  4. 바깥 dict로 문자열 이름을 해시로 찾고 안쪽 사전으로 이웃과 간선 속성을 읽는다. 정점이 늘면 목록 하나만 더하면 되지만 고정 크기 2차원 배열로 만든 인접행렬이면 전체를 다시 만들어야 한다.
