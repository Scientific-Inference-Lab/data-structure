개념 확인: Topological Ordering and Applications

의존 관계를 DAG로 적고 DFS 종료 시각과 진입 차수로 위상정렬을 구한다.

문제 1

의존 관계를 DAG로

과목 선수 관계는 다음과 같다. 자료구조는 프로그래밍 이후, 알고리즘은 자료구조와 이산수학 이후, 기계학습은 알고리즘과 확률 이후에 수강한다.

  1. 정점과 간선의 방향을 정해 간선 목록을 적는다.
  2. 처음에 바로 수강할 수 있는 과목을 적고, 그런 정점이 DAG에 반드시 있는 이유를 적는다.
  3. ‘알고리즘은 기계학습 이후’라는 조건을 잘못 추가하면 어떤 일이 생기는지 적는다.
  4. DAG라는 이름의 세 낱말이 각각 무엇을 뜻하는지 적는다.
해설 펼치기
  1. 과목이 정점이고 ‘먼저 들을 과목 → 나중 과목’이 간선이다. 프로그래밍→자료구조, 자료구조→알고리즘, 이산수학→알고리즘, 알고리즘→기계학습, 확률→기계학습.
  2. 프로그래밍, 이산수학, 확률이다. 들어오는 간선이 없는 정점이 하나도 없다면 간선을 거슬러 계속 갈 수 있어 유한한 그래프에서 사이클이 생긴다.
  3. 알고리즘→기계학습→알고리즘 사이클이 생겨 서로가 서로보다 먼저여야 하므로 수강 순서를 정할 수 없다.
  4. directed(방향이 있는), acyclic(사이클이 없는), graph(그래프)다.
문제 2

종료 시각 구하기

문제 2~4, 문제 5의 3, 문제 6은 작업 A~F와 선후 간선 A→B, A→C, B→D, C→D, D→E, F→C로 이루어진 그래프 T를 쓴다. 문제 2~4의 DFS는 정점을 알파벳 순으로 시작하고 이웃도 목록 순서대로 본다.

  1. T에서 DFS를 하며 시각을 1부터 올릴 때 각 정점의 발견 시각과 종료 시각을 적는다.
  2. 종료 시각 내림차순으로 위상정렬을 적는다.
  3. C를 처리할 때 이웃 D의 상태와, 그 상태에서도 C가 D보다 앞에 놓이는 이유를 적는다.
  4. F를 처리할 때 이웃 C의 상태를 적고, 종료 시각으로 F가 C보다 앞에 오는지 확인한다.
해설 펼치기
  1. A 1/10, B 2/7, D 3/6, E 4/5, C 8/9, F 11/12다.
  2. F, A, C, B, D, E다.
  3. D는 이미 끝남 상태다. D가 C보다 먼저 끝났으므로(6 < 9) 내림차순에서 C가 앞에 온다.
  4. C는 끝남 상태이고 종료 시각 9 < 12이므로 F가 앞에 온다.
문제 3

순서 확인하기

문제 2의 원래 그래프 T와 DFS 순서를 쓴다.

  1. A, F, B, C, D, E가 T의 위상정렬인지 간선을 하나씩 확인해 판정한다.
  2. A, B, D, C, E, F가 위상정렬인지 판정하고, 어긋난 간선을 모두 적는다.
  3. T의 위상정렬이 여러 개인 이유를 선후 관계가 없는 정점 쌍 하나로 설명한다.
  4. DFS 종료 시각으로 위상정렬하는 방식의 비용을 적고, 이 방식에 힙 정렬처럼 O(n log n)이 들지 않는 이유와 두 정렬의 결과 조건 차이를 적는다.
해설 펼치기
  1. 위상정렬이다. 여섯 간선 모두 출발 정점이 도착 정점보다 앞에 있다.
  2. 아니다. C→D(D가 C보다 앞)와 F→C(C가 F보다 앞)가 어긋난다.
  3. A와 F 사이에는 어느 방향으로도 경로가 없어 둘의 순서가 자유롭다. 그래도 간선을 거스르는 나열은 틀린 답이다.
  4. DFS O(n + m)에 종료 순서 뒤집기 O(n)으로 O(n + m)이다. 이 DFS 방식은 값을 비교해 정렬하지 않는다. 힙 정렬은 키의 비내림차순, 위상정렬은 모든 간선이 앞에서 뒤로 가는 조건을 만족한다. 진입 차수 방식에서 작은 정점을 min-heap으로 고르면 비용에 O(n log n)이 추가되지만, 위상정렬의 결과 조건은 같다.
문제 4

사이클 탐지

문제 2의 원래 그래프 T와 DFS 순서를 쓴다.

  1. T에 간선 E→B를 추가했을 때 생기는 사이클을 적는다.
  2. 추가한 그래프에서 A부터 DFS를 할 때 사이클을 알아채는 순간의 간선과, 그 순간 ‘처리 중’인 정점을 적는다.
  3. 그 간선이 사이클의 증거가 되는 이유를 적는다.
  4. T(추가 전)에서 C를 처리할 때 이미 방문한 D를 만났지만 사이클이 아니다. 처리 중과 끝남을 구분하지 않고 ‘방문한 정점을 다시 만나면 사이클’로 판정하면 무엇이 잘못되는지 적는다.
해설 펼치기
  1. B → D → E → B다.
  2. E를 처리하며 간선 E→B를 볼 때다. 처리 중인 정점은 A, B, D, E다.
  3. 처리 중인 B에서 E까지 현재 DFS 경로 B→D→E가 있고, E→B가 그 경로와 함께 유향 사이클을 이룬다.
  4. D는 끝남 상태라 현재 경로 위에 없다. 구분하지 않으면 사이클이 없는 T도 사이클이 있다고 잘못 판정한다.
문제 5

탐색으로 답하기

무향 그래프 U는 정점 1~8과 간선 {1, 2}, {2, 3}, {4, 5}, {6, 7}, {7, 8}로 이루어진다.

  1. 1에서 탐색했을 때 표시되는 정점을 적고, U가 연결 그래프인지 판정한다.
  2. 연결 요소를 세는 절차를 따라 탐색을 시작하는 정점(번호가 작은 것부터)과 요소 개수를 적는다.
  3. 문제 2의 원래 유향 그래프 T에서 A부터 탐색해 모든 정점에 닿지 않았다는 결과만으로 무엇을 말할 수 있고, 무향 그래프의 연결성 판정을 그대로 쓸 수 없는 이유를 적는다.
  4. 다음 질문에 필요한 탐색과 추가로 기록할 것을 적는다. (가) 간선 몇 개 거리인가? (나) 사이클이 있는가? (다) 먼저 할 일의 순서는 무엇인가?
해설 펼치기
  1. 1, 2, 3이다. 4~8에 닿지 않으므로 연결 그래프가 아니다.
  2. 1(1, 2, 3), 4(4, 5), 6(6, 7, 8)에서 시작해 3개다.
  3. A에서 F로 가는 경로가 없다는 것만 말할 수 있다. T에서 F도 A와 B에 닿지 못한다. 유향 그래프에서는 출발 정점에 따라 도달 집합이 달라지며, 한쪽으로 닿아도 반대 방향으로 닿는다는 보장은 없다. 한 번의 탐색 결과를 모든 정점 쌍의 경로로 일반화할 수 없다.
  4. (가) BFS와 거리, (나) DFS와 세 가지 상태 또는 진입 차수와 남은 진입 차수, (다) DFS와 종료 시각 또는 진입 차수와 남은 진입 차수다.
문제 6

진입 차수로 순서 구하기

문제 2의 원래 그래프 T를 쓴다. 남은 정점 중 진입 차수가 0인 정점을 하나씩 꺼내 답의 뒤에 적고, 그 정점에서 나가는 간선을 지운다. 진입 차수가 0인 정점이 여럿이면 매번 알파벳 순으로 이름이 가장 작은 정점을 고른다.

  1. 각 정점의 초기 진입 차수를 표로 적는다.
  2. 매 단계에서 꺼내기 직전 진입 차수가 0인 정점들, 꺼낸 정점, 간선을 지운 뒤 바뀐 진입 차수를 적는다. 최종 위상 순서를 적는다.
  3. 원래 T에 간선 E→B를 추가하고 처음부터 같은 규칙으로 처리한다. 꺼낸 순서, 멈출 때 남은 정점과 각 진입 차수를 적고, 전체 위상정렬을 구할 수 없는 이유를 설명한다.
해설 펼치기
  1. 각 정점으로 들어오는 간선을 세면 다음과 같다. C에는 A와 F에서, D에는 B와 C에서 간선이 들어온다.
정점초기 진입 차수
A0
B1
C2
D2
E1
F0
  1. 매번 현재 진입 차수가 0인 정점 전체에서 가장 작은 이름을 고른다. 다음 표의 차수는 꺼낸 정점의 나가는 간선을 지운 뒤의 값이다.
꺼내기 직전 차수 0인 정점들꺼낸 정점바뀐 진입 차수
A, FAB: 1→0, C: 2→1
B, FBD: 2→1
FFC: 1→0
CCD: 1→0
DDE: 1→0
EE없음

최종 위상 순서는 A, B, F, C, D, E다. A를 꺼낸 뒤 새로 준비된 B도 F와 함께 비교하므로 B가 먼저 나온다. C는 A→C만 지워서는 차수가 1이며, F→C까지 지워야 0이 된다.

  1. E→B를 더하면 초기 진입 차수는 A~F 순서로 0, 2, 2, 2, 1, 0이다. A를 꺼내면 B는 2→1, C는 2→1이 된다. 다음에 F를 꺼내면 C가 1→0이 되고, C를 꺼내면 D가 2→1이 된다. 꺼낸 순서는 A, F, C이며, 남은 정점은 B, D, E이고 진입 차수는 각각 1, 1, 1이다. 남은 간선 B→D, D→E, E→B가 사이클을 이루므로 더 꺼낼 차수 0인 정점이 없다. 여섯 정점 중 세 정점만 답에 적혔으므로 전체 위상정렬은 불가능하다.
