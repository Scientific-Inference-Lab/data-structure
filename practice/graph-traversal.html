개념 확인: Graph Traversal

큐와 스택으로 그래프를 순회하며 방문 순서·거리·경로를 추적한다.

문제 1

frontier와 표시

  1. frontier는 무엇을 담는지 적는다.
  2. 유향 간선 A→B, B→C, C→A만 있는 그래프에서 seen 표시 없이 A부터 탐색하면 어떤 일이 생기는지 적는다.
  3. BFS에서 정점을 표시하는 시점과, 이 예제의 스택 DFS에서 표시하는 시점을 적는다.
  4. 스택 DFS에서 꺼낼 때 표시하면 같은 정점이 스택에 여러 번 들어갈 수 있다. 이때 꺼낸 뒤 무엇을 해야 하는지 적는다.
해설 펼치기
  1. 다음에 꺼내 확인할 정점을 담는다. 스택 DFS에서는 같은 정점이 여러 번 들어갈 수 있다.
  2. A → B → C → A로 왔던 정점에 계속 되돌아가 탐색이 끝나지 않는다.
  3. BFS는 큐에 넣을 때 표시한다. 이 스택 DFS는 정점을 처음 꺼냈을 때 표시한다.
  4. 꺼낸 정점이 이미 표시되어 있으면 건너뛴다.
문제 2

BFS 따라가기

문제 2~5는 유향 그래프 G의 인접리스트 0: [1, 2], 1: [3, 4], 2: [4], 3: [5], 4: [5], 5: [], 6: [0]을 쓴다. 이웃은 목록 순서대로 본다.

  1. 정점 0에서 BFS를 할 때 각 정점을 꺼내기 직전의 큐 상태와 방문 순서를 적는다.
  2. 각 정점의 거리(간선 수)를 적는다.
  3. 정점 2를 방문할 때 이웃 4를 큐에 다시 넣지 않는 이유를 적는다.
  4. G의 n과 m을 세어 인접리스트 BFS의 비용을 적고, 인접행렬이면 비용이 어떻게 되는지 적는다.
해설 펼치기
  1. 큐는 [0], [1, 2], [2, 3, 4], [3, 4], [4, 5], [5] 순이고 방문 순서는 0, 1, 2, 3, 4, 5다.
  2. 0은 0, 1·2는 1, 3·4는 2, 5는 3이다. 6은 닿지 않는다.
  3. 4는 정점 1을 방문할 때 큐에 넣으며 이미 표시했기 때문이다.
  4. n = 7, m = 8이다. 인접리스트는 O(n + m)이고, 인접행렬은 정점마다 한 행 n칸을 보므로 O(n²)이다.
문제 3

부모와 거리

1~3은 문제 2의 G에서 수행한 BFS 결과를 쓴다. 4는 별도의 가중치 그래프다.

  1. 문제 2의 BFS에서 각 정점의 부모를 적는다.
  2. 부모를 거슬러 0에서 5까지의 경로를 복원하는 과정을 단계별로 적는다.
  3. 0→2→4→5도 간선 3개 경로인데 BFS가 0→1→3→5를 돌려준 이유를 적는다.
  4. 간선 A→D의 비용이 10이고 A→B, B→C, C→D의 비용이 각각 1이다. BFS가 A에서 D까지 주는 경로와 그 비용, 비용 합이 가장 작은 경로를 적는다.
해설 펼치기
  1. 1·2의 부모는 0, 3·4의 부모는 1, 5의 부모는 3이다. 0은 시작점이라 부모가 없고, 6은 닿지 않아 기록이 없다.
  2. 목록에 5를 넣고 부모 3, 1, 0으로 올라가며 넣어 [5, 3, 1, 0]을 만든 뒤 뒤집어 0 → 1 → 3 → 5를 얻는다.
  3. 5를 처음 발견한 정점이 3이었기 때문이다(3이 4보다 먼저 큐에서 나왔다). 두 경로 모두 최단 간선 수 3이다.
  4. BFS는 간선 1개인 A→D를 주며 비용은 10이다. 비용 합이 가장 작은 경로는 A→B→C→D로 3이다. BFS 거리는 간선 수이므로 가중치 합 최단을 보장하지 않는다.
문제 4

DFS 따라가기

문제 2의 유향 그래프 G와 이웃 순서를 쓴다.

  1. 정점 0에서 재귀 DFS를 할 때 방문(처리 시작) 순서와 끝남 순서를 적는다.
  2. 정점 4를 처리할 때 이웃 5로 들어가지 않는 이유를 적는다.
  3. 강의의 dfs_stack처럼 꺼낼 때 표시하고 이미 표시한 이웃도 넣되, 이웃을 뒤에서부터 넣는 스택 DFS로 0에서 시작한다. 하나를 꺼내 처리하거나 건너뛴 직후의 스택 상태(오른쪽이 맨 위)와 방문 순서를 적는다.
  4. 재귀 DFS가 정점 3에 막 들어가고 이웃을 보기 전, ‘처리 중’인 정점을 모두 적는다.
해설 펼치기
  1. 방문 0, 1, 3, 5, 4, 2. 끝남 5, 3, 4, 1, 2, 0.
  2. 5는 3을 처리할 때 이미 방문해 표시했고 끝남 상태이기 때문이다.
  3. 0 처리 후 [2, 1], 1 후 [2, 4, 3], 3 후 [2, 4, 5], 5 후 [2, 4], 4 후 [2, 5]다. 4의 이웃 5는 이미 표시했지만 넣는다. 다음에 꺼낸 5는 표시되어 있어 건너뛰어 [2], 2 처리 후 [4], 다시 꺼낸 4도 건너뛰어 []이다. 방문 순서 0, 1, 3, 5, 4, 2로 재귀와 같다.
  4. 0, 1, 3이다. 0과 1은 재귀 호출이 끝나기를 기다리고 있고, 3은 막 호출되었다.
문제 5

BFS와 DFS 고르기

문제 2의 유향 그래프 G와 이웃 순서를 쓴다.

  1. G에서 0부터 탐색을 마친 뒤 방문하지 않은 정점과 그 뜻을 적는다.
  2. G의 모든 정점을 한 번씩 방문하려면 어떻게 하는지 적는다.
  3. 다음 세 질문에 BFS와 DFS 중 무엇을 쓸 수 있는지 적는다. (가) 0에서 5에 닿는가 (나) 0에서 5까지 간선 몇 개가 최소인가 (다) 미로에서 한 갈래를 끝까지 따라가 본 뒤 되돌아오는 탐색
  4. 같은 그래프와 출발점에서도 두 사람이 구한 DFS 방문 순서가 다를 수 있는 이유를 적는다.
해설 펼치기
  1. 6이다. 0에서 닿을 수 없다(6→0은 있지만 0→6 경로가 없다).
  2. 방문하지 않은 정점이 남아 있으면 그 정점에서 탐색을 다시 시작한다. 6에서 시작하면 6만 새로 방문한다.
  3. (가)는 둘 다, (나)는 BFS, (다)는 DFS다.
  4. 이웃을 보는 순서가 다르면 먼저 따라가는 갈래가 달라진다.
