Standing the Tree Back Up↗

개념 확인: AVL Rotations

회전으로 기운 부분 트리를 다시 세우고 네 불균형 경우를 판정한다.

문제 1

회전이 지키는 것

노드 S의 왼쪽 자식이 X이고, X의 왼쪽·오른쪽 부분 트리가 A, B, S의 오른쪽 부분 트리가 C다. S를 축으로 오른쪽 회전한다.

  1. 회전 뒤 루트와 각 부분 트리 A, B, C가 붙는 자리를 적는다.
  2. 회전 전후의 중위 순서를 적고 BST 조건이 유지되는 이유를 적는다.
  3. 회전의 비용과 그 이유를 적는다.
  4. 왼쪽 회전은 언제 쓰고 무엇이 올라가는지 적는다.
해설 펼치기
  1. X가 루트가 되고, A는 X의 왼쪽에 그대로, S가 X의 오른쪽, B는 S의 왼쪽, C는 S의 오른쪽에 붙는다.
  2. 전후 모두 A, X, B, S, C다. A < X < B < S < C 순서가 그대로이므로 BST 조건을 만족한다.
  3. 참조 몇 개만 옮기므로 담긴 값의 수와 관계없이 O(1)이다.
  4. 오른쪽이 무거울 때 쓰며 오른쪽 자식 노드가 올라간다. 오른쪽 회전의 거울상이다.
문제 2

바깥 경우: 한 번 회전

  1. 빈 AVL 트리에 40, 50, 60을 넣을 때 불균형이 생기는 노드와 균형 인수, 경우 이름, 회전, 결과 트리를 적는다.
  2. 60, 50, 40을 넣으면 같은 항목이 어떻게 되는지 적는다.
  3. 불균형 노드의 bf가 +2이고 무거운 자식의 bf가 0 이상일 때와 음수일 때를 구분해 경우 이름을 적는다.
  4. 삽입에서 회전의 축으로 고르는 노드를 적는다.
해설 펼치기
  1. 60을 넣으면 40의 bf가 −2다. 오른쪽 자식 50의 bf도 음수라 right-right이고, 40에서 왼쪽 회전해 50(40, 60)이 된다.
  2. 40을 넣으면 60의 bf가 +2이고 50의 bf가 양수라 left-left다. 60에서 오른쪽 회전해 50(40, 60)이 된다.
  3. 0 이상이면 left-left(바깥), 음수면 left-right(안쪽)다.
  4. |bf| = 2가 된 노드 가운데 새로 넣은 값에서 가장 가까운 노드다.
문제 3

안쪽 경우: 두 번 회전

  1. 빈 AVL 트리에 30, 10, 20을 넣을 때 불균형 노드, 두 균형 인수의 부호, 경우 이름을 적는다.
  2. 첫 회전과 둘째 회전의 축과 방향, 각 회전 뒤 모양을 적는다.
  3. 30에서 오른쪽 회전 한 번만 하면 왜 풀리지 않는지 적는다.
  4. 10, 30, 20을 넣는 경우의 이름과 두 회전을 적는다.
해설 펼치기
  1. 30의 bf가 +2, 무거운 자식 10의 bf가 −1이라 반대 방향으로 꺾인 left-right(안쪽)다.
  2. 첫 회전은 무거운 자식 10에서 왼쪽 회전해 30(20(10, -), -)이 되고, 둘째는 불균형 노드 30에서 오른쪽 회전해 20(10, 30)이 된다.
  3. 한 번 돌리면 안쪽 노드가 반대쪽으로 넘어가 반대로 기울어 여전히 불균형하다.
  4. right-left다. 30에서 오른쪽 회전한 뒤 10에서 왼쪽 회전해 20(10, 30)이 된다.

주의: 두 회전을 같은 자리에서 반대 방향으로 하면 원래 모양으로 돌아오므로 축이 달라야 한다.

문제 4

정렬된 값을 AVL에 넣기

  1. 빈 AVL 트리에 1부터 7까지 차례로 넣을 때 회전이 일어나는 삽입, 축 노드, 경우 이름을 모두 적는다.
  2. 최종 트리와 높이를 적고 보통 BST에 같은 순서로 넣었을 때의 높이와 비교한다.
  3. 삽입 뒤 첫 불균형 조상에서 회전하면 그 위를 더 확인하지 않아도 되는 이유를 적는다.
  4. AVL 삽입 전체 비용을 단계별로 적는다.
해설 펼치기
  1. 3을 넣을 때 1(right-right), 5를 넣을 때 3(right-right), 6을 넣을 때 루트 2(right-right), 7을 넣을 때 5(right-right)에서 왼쪽 회전한다. 모두 네 번이다.
  2. 4(2(1, 3), 6(5, 7))이고 높이 2다. 보통 BST는 한 줄이 되어 높이 6이다.
  3. 삽입으로 높이가 1 늘어 생긴 불균형이 회전 뒤 삽입 전 높이로 돌아가므로 그 위 조상들의 높이는 바뀌지 않는다.
  4. 자리 찾기 O(log n), 같은 길을 올라오며 높이 갱신 O(log n), 회전 O(1)(최대 두 번)으로 전체 O(log n)이다.
문제 5

균형 트리를 고르는 기준

다음 문장이 맞는지 판단하고 틀리면 고친다.

  1. 레드-블랙 트리는 부분 트리의 높이 차이로 균형을 잰다.
  2. AVL 트리와 레드-블랙 트리 모두 탐색의 최악 비용이 O(log n)이다.
  3. 키의 범위 질의와 정렬 순회가 필요하면 해시테이블이 균형 탐색 트리보다 알맞다.
  4. 균형 트리는 좋은 입력에서도 BST보다 탐색 차수가 낮다.
해설 펼치기
  1. 틀렸다. 레드-블랙 트리는 노드의 색 규칙으로 높이를 제한하고, 높이 차이를 재는 것은 AVL 트리다.
  2. 맞다. AVL이 보통 더 엄격해 높이가 낮지만 실제 성능은 구현과 작업 부하에 따라 다르다.
  3. 틀렸다. 범위 질의와 정렬 순회에는 균형 탐색 트리가 알맞고, 동등성 조회에는 해시테이블이 흔한 선택이다.
  4. 틀렸다. 좋은 입력에서는 둘 다 O(log n)이고, 차이는 나쁜 입력에서 BST가 O(n)이 된다는 점이다. 균형 트리는 회전과 상태 저장이라는 값을 치른다.
