개념 확인: Graphs and Edges

정점과 간선으로 관계를 적고 경로와 도달 가능성을 판정한다.

문제 1

트리가 아닌 이유

문제 1~4는 정점 A, B, C, D, E와 유향 간선 A→B, A→C, B→D, C→D, D→B, E→A로 이루어진 그래프 G를 쓴다.

  1. G의 n과 m을 적는다.
  2. G가 트리가 아닌 이유를 두 가지 적는다.
  3. 연결리스트와 이진트리를 그래프로 볼 때 각각 정점과 간선이 무엇인지 적는다.
해설 펼치기
  1. n = 5, m = 6이다.
  2. D로 들어오는 간선이 B와 C 두 개라 부모가 둘인 셈이고, B → D → B처럼 출발점으로 되돌아오는 경로가 있다. 트리에는 둘 다 없다.
  3. 연결리스트는 노드가 정점, next 연결이 간선이다. 이진트리는 노드가 정점, 최대 두 자식 노드로 가는 연결이 간선이다.
문제 2

이웃과 간선의 종류

문제 1의 원래 유향 그래프 G를 쓴다.

  1. A의 진출 이웃과 D의 진입 이웃을 적는다.
  2. A와 B가 인접한지, B에서 A로 가는 간선이 있는지 적는다.
  3. G에 자기 루프나 평행 간선이 있는지 확인하고 단순 그래프인지 판정한다.
  4. 무향 간선 {A, B}를 유향 그래프로 나타내는 방법을 적는다.
해설 펼치기
  1. A의 진출 이웃은 B, C다. D의 진입 이웃은 B, C다.
  2. A→B가 있어 인접하다. B→A는 없으므로 B에서 A로 직접 갈 수 없다.
  3. (i, i) 꼴의 간선도, 같은 두 정점을 같은 방향으로 잇는 간선 여러 개도 없다. 단순 그래프다.
  4. A→B와 B→A 두 간선을 함께 둔다.
문제 3

경로와 도달 가능성

문제 1의 원래 유향 그래프 G를 쓴다.

  1. A에서 B로 가는 경로를 두 개 적고, 그중 단순 경로를 고른다.
  2. A→B→D→B가 경로인지와 단순 경로인지 적는다.
  3. 길이 0인 경로는 출발 정점 자신에 머문다. 이 경로도 포함해 A에서 도달할 수 있는 정점과 E에서 도달할 수 있는 정점을 적는다.
  4. B에서 A로 도달할 수 있는지 적고, A에서 B로는 되는데 반대는 안 되는 이유를 적는다.
해설 펼치기
  1. A→B, A→C→D→B다. 둘 다 같은 정점을 두 번 지나지 않아 단순 경로다.
  2. 연속한 두 정점마다 간선이 있어 경로이지만 B를 두 번 지나므로 단순 경로가 아니다.
  3. A에서는 A, B, C, D에 닿는다. E에서는 E, A, B, C, D 모두에 닿는다.
  4. 닿을 수 없다. B, C, D에서 나가는 간선은 모두 B, D 쪽이고 A로 들어오는 간선은 E→A뿐이다. 유향 경로는 화살표를 거슬러 갈 수 없다.
문제 4

그래프 ADT

문제 1의 원래 유향 그래프 G를 쓴다.

  1. hasEdge(A, C), hasEdge(C, A), outEdges(D)의 결과를 적는다.
  2. 정점 D를 지울 때 함께 지워야 하는 간선과 지운 뒤의 m을 적는다.
  3. 간선을 남기고 정점만 지우면 생기는 문제를 적는다.
  4. 그래프 ADT가 정한 것과 정하지 않은 것을 적고, hasEdge의 비용을 아직 말할 수 없는 이유를 적는다.
해설 펼치기
  1. 참, 거짓, [B]다.
  2. B→D, C→D, D→B를 지운다. m은 6 − 3 = 3이다.
  3. 없는 정점을 가리키는 연결이 남는다.
  4. ADT는 연산과 그 뜻을 정하고 저장 위치와 비용은 정하지 않는다. 비용은 그래프의 저장 방법을 정한 뒤에야 알 수 있다.
문제 5

문제를 그래프로 적기

  1. 시험 시간표에서 같은 학생이 듣는 두 과목은 같은 시간에 둘 수 없다. 정점과 간선이 각각 무엇이고 방향이 필요한지 적는다.
  2. 도시 사이 도로의 이동 시간을 담으려면 어떤 그래프가 알맞은지 적는다.
  3. 퍼즐의 상태 공간을 그래프로 적을 때 정점과 간선을 적는다.
  4. 정점을 번호가 아닌 과목 이름으로 부르려면 무엇을 더 두어야 하는지 적는다.
해설 펼치기
  1. 과목이 정점, ‘함께 배정할 수 없음’이 간선이다. 관계가 서로 대칭이라 방향이 필요 없다.
  2. 간선마다 이동 시간을 붙인 가중치 그래프다. 일방통행이 있으면 유향 간선을 쓴다.
  3. 보드 상태가 정점, 한 번에 가능한 이동이 간선이다.
  4. 과목 이름을 키로 정점을 찾는 대응표를 두고, 정점을 찾는 연산을 추가한다.
