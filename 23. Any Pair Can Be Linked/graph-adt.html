Graph ADT

그래프 ADT는 정점과 간선을 갱신하고 관계를 질의하는 연산의 뜻을 정한다. 저장 방법과 연산 비용은 구현이 정한다.

갱신정점이나 간선을 추가·삭제해 그래프를 바꾼다.
질의간선 존재 여부와 한 정점의 이웃 목록을 돌려준다.
ADT와 구현연산의 뜻을 먼저 정하고 저장 위치와 비용은 구현이 정한다.

같은 그래프에서 갱신과 질의는 서로 다른 결과를 만든다

기준 그래프 G = ({A, B, C}, {A→B, A→C})에 연산을 한 번 적용하면 갱신 연산은 그래프를 바꾸고 질의 연산은 그래프를 그대로 둔 채 값을 돌려준다.
