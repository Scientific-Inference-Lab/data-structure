When Do We Visit the Root↗

Depth First Tree Traversals

트리 순회는 트리의 모든 노드를 정해진 순서로 한 번씩 방문하는 절차다. 전위 순회, 중위 순회, 후위 순회는 자식 노드를 왼쪽부터 처리하되 루트를 두 부분 트리보다 먼저, 사이에, 나중에 처리하는 위치만 다르다.

전위 순회(preorder traversal)루트 → 왼쪽 → 오른쪽 순서다.
중위 순회(inorder traversal)왼쪽 → 루트 → 오른쪽 순서다.
후위 순회(postorder traversal)왼쪽 → 오른쪽 → 루트 순서다.

visit 문장의 위치가 방문 순서를 바꾼다

같은 트리에서 순회 방식을 바꾸면 재귀 함수의 visit 문장 위치와 출력 순서가 바뀐다. 방문 횟수를 옮기면 그때까지 처리한 노드와 방금 처리한 노드가 표시된다.

명시적 스택은 오른쪽 자식 노드를 먼저 push해 전위 순회를 만든다

stack = [A]에서 시작해 pop한 노드를 방문하고 오른쪽, 왼쪽 자식 노드 순서로 push한다. pop 횟수를 옮기면 방문한 노드와 스택의 내용이 바뀐다.

순회 시간은 노드 수에, 추가 공간은 높이에 달려 있다

노드 수와 트리 모양을 바꾸면 방문 횟수와, 가장 깊은 노드를 처리하는 순간 동시에 열려 있는 재귀 호출 수가 바뀐다.
