같은 결과를 만드는 Python 코드도 내부 작업이 다르다. 새 목록 생성, 원소 이동, 값 비교 가운데 어느 작업이 생기는지가 입력 크기에 따른 비용을 가른다.

append와 +기존 목록 변경과 새 목록 생성을 구분한다.
pop 위치앞에서 삭제하면 뒤 원소가 왼쪽으로 이동한다.
in 조회list와 dict에 모두 없는 값을 찾아 두 조회를 같은 조건에서 비교한다.

구조에서 생기는 작업을 단계별로 비교한다

비교 항목과 원소 수, 단계에 따라 두 코드의 누적 작업이 달라진다. 상자 수는 코드 구조로 셀 수 있는 작업이며 실행 시간이 아니다.
