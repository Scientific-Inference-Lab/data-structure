Timing A Run

실행 시간(running time)은 프로그램이 실행을 시작해 끝낼 때까지 걸린 시간이다. 호출을 여러 번 묶어 재고, 묶음 시간을 호출당 시간으로 바꾼 뒤 중앙값으로 요약한다.

실측(benchmark)코드를 실행해 걸린 시간을 잰다. 같은 결과를 내는 구현도 시간은 다를 수 있다.
반복 묶음짧은 호출을 여러 번 실행해 한 묶음으로 잰다.
호출당 중앙값묶음 시간을 호출 수로 나누고 가운데 값을 쓴다.

측정 구간과 반복 묶음을 한 계산으로 연결한다

세 함수는 모두 1 + 2 + ··· + n을 반환한다. 함수와 입력 크기, 묶음당 호출 수, 반복 묶음 수를 바꾸면 묶음 시간과 호출당 환산값, 중앙값이 함께 바뀐다.

비교 조건 가운데 하나가 달라지면 해석도 달라진다

실행 시간을 비교하려면 코드뿐 아니라 컴퓨터, 측정 범위와 입력 크기도 같아야 한다.
