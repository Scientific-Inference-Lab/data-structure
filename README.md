# Data Structure

[Course materials](https://scientific-inference-lab.github.io/data-structure/)

How data representations affect the cost of operations, from data abstraction and arrays to linked lists, stacks, queues, and hash tables.

Lecture slides, interactive topic pages, and concept-check problems. Learning materials are in Korean.
