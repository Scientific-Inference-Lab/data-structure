Reading Code As A Function

코드의 실행 경로를 줄별 횟수로 바꾸면 정확한 비용 함수가 나타난다. 연속 블록은 더하고, 중첩 반복은 곱하며, 크기를 절반으로 줄이는 반복에는 로그가 나타난다.

연속 블록각 블록의 실행 수를 더한다.
중첩 반복바깥 반복마다 안쪽 반복이 다시 실행된다.
절반 반복n을 1이 될 때까지 반으로 줄이는 횟수는 ⌊log₂ n⌋이다.

한 단계가 어느 코드 줄의 비용인지 연결한다

단계는 실제 반복 본문이 실행되는 순서를 따른다. 반복 제어와 함수 호출 비용은 이 모형에서 세지 않는다.

정확한 식에서 증가 차수를 분리한다

위 절에서 고른 입력 크기 n과 코드 예제를 그대로 쓴다. 같은 n에서도 반복 구조가 다르면 정확한 연산 수와 최고차항이 달라진다.

정확한 작업 수를 함수로 바꾼 뒤에는 시간과 공간을 한 값으로 섞지 않는다. 더 빠른 방법이 언제나 추가 공간도 더 적게 쓰는 것은 아니다.
