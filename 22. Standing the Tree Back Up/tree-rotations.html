AVL Rotations↗

Tree Rotations

회전(rotation)은 부모와 자식 노드의 관계를 국소적으로 바꾸되 중위 순서를 보존하는 연산이다. 참조 몇 개만 옮기므로 담긴 값의 수와 상관없이 O(1)이고, AVL 트리에서는 불균형 부분 트리의 높이를 삽입 전 수준으로 되돌리는 데 쓴다.

오른쪽 회전(right rotation)왼쪽이 무거울 때 왼쪽 자식 노드를 올린다. 코드 이름은 rotate_right다.
왼쪽 회전(left rotation)오른쪽이 무거울 때 오른쪽 자식 노드를 올린다. 두 회전은 서로의 거울상이다.
보존하는 것A < X < B < S < C의 순서가 그대로라 회전 뒤에도 BST 조건을 만족한다.

회전은 부모와 자식을 바꾸고 가운데 부분 트리 하나만 옮기며 중위 순서를 지킨다

노드 S의 왼쪽 자식 노드가 X이고 A, B, C가 부분 트리다. 회전하면 루트와 가운데 부분 트리 B의 부모가 바뀌지만 중위 순서는 그대로다.

바깥으로 기운 불균형은 불균형 노드를 축으로 한 번 돌리면 풀린다

빈 AVL 트리에 값 세 개를 넣는다. 삽입 순서에 따라 트리가 기우는 방향과 회전의 축, 방향이 달라진다.
