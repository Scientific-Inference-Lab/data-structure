Red Black Trees

레드-블랙 트리(Red-Black tree)는 각 노드에 빨강 또는 검정 색을 붙이고 색 규칙으로 높이를 제한하는 BST다. AVL 트리가 부분 트리의 높이 차이로 균형을 재는 것과 달리 색 규칙을 쓰며, 조금 느슨하지만 두 구조 모두 최악의 경우 O(log n)을 보장한다.

검정 노드 수루트에서 빈 자리(nil)까지 모든 경로의 검정 노드 수가 같다.
연속된 빨강 금지빨강 노드의 자식 노드는 빨강일 수 없다.
높이 제한두 색 규칙으로 높이를 2 log₂ n 이하로 제한해 최악의 경우 O(log n)을 지킨다.

균형 트리는 입력 순서가 나빠도 높이를 로그 수준으로 지킨다

1부터 15까지를 같은 순서로 보통 BST와 AVL 트리에 넣는다. 입력 순서를 바꾸면 두 트리의 모양과 가장 깊은 키까지 방문하는 노드 수가 바뀐다.

순서가 필요한 질의에는 균형 탐색 트리, 동등성 조회에는 해시테이블을 고른다

키 42, 7, 19, 3, 25, 11을 이 순서로 넣은 해시테이블과 균형 탐색 트리에 같은 질의를 한다. 질의를 바꾸면 두 구조가 결과를 얻는 방법과 확인하는 키가 바뀐다.

AVL 트리와 레드-블랙 트리는 재는 것이 달라도 같은 최악 보장을 준다

두 균형 트리와 보통 BST의 균형 기준과 탐색 비용을 나란히 놓는다.

두 균형 트리는 서로 다른 규칙으로 같은 목표, 곧 입력 순서와 무관한 O(log n) 높이를 지킨다. 회전 절차보다 먼저 각 구조가 어떤 규칙으로 높이를 제한하는지를 비교하고, 자료구조는 필요한 순서와 질의 종류를 기준으로 고른다.
